# AGENTS.md — Awesome Marko

## Project Overview

This is an **Awesome List** for the Marko PHP framework (https://marko.build). It follows the [awesome](https://github.com/sindresorhus/awesome) list conventions.

## Technology Context

- **Target Framework**: Marko (PHP 8.5+, modular, attribute-based)
- **Purpose**: Curated list of Marko frameworks, libraries, modules, and software
- **License**: CC0 1.0 Universal (public domain dedication)

## File Structure

```
.
├── README.md              # Main awesome list
├── CONTRIBUTING.md        # Contribution guidelines
├── CODE_OF_CONDUCT.md     # Contributor Covenant CoC
├── LICENSE                # CC0 license
├── .gitignore             # Git ignore rules
└── AGENTS.md              # This file
```

## Content Guidelines

- Entries must be Marko-related (modules, libraries, tools, resources)
- Format: `- [name](url) - Description.`
- Sort alphabetically within categories
- Keep descriptions concise and informative
- Only submit items that are actively maintained

## Editing Conventions

- Use Markdown for all documentation
- Maintain the ASCII art header in README.md
- Update the table of contents when adding new categories
- Use CC0 for all content contributions

## No Build Step

This is a documentation-only repository. No build tools, dependencies, or CI required.
