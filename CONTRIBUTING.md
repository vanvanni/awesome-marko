# Contributing to Awesome Marko

Thank you for your interest in contributing to Awesome Marko! This document provides guidelines and instructions for contributing.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Add your entry** to the appropriate section in `README.md` (Modules, Plugins, or Misc).
3. **Ensure your entry follows the format** described below.
4. **Submit a pull request** with a clear description of what you're adding.

## Contribution Guidelines

### Quality Standards

- **Only submit items you have personally used or vetted.** We want to maintain high quality.
- **Ensure the project is actively maintained.** Stale or abandoned projects may be removed.
- **Check for duplicates** before submitting. Search the README to make sure the item isn't already listed.
- **Make sure the project is related to Marko.** It should be a Marko module, library, tool, or resource.

### Entry Format

Each entry should follow this format:

```markdown
- [project-name](https://github.com/username/repo) - Brief description of what the project does.
```

Rules:
- Use the project's actual name as the link text.
- Keep descriptions concise but informative (under 100 characters if possible).
- End descriptions with a period.
- Place entries in the appropriate category. If unsure, open a discussion.
- Sort entries alphabetically within their category.

### Adding a New Category

If your entry doesn't fit into any existing category:

1. Open an issue or discussion first to propose the new category.
2. If approved, add the category to both the table of contents and the main content.

### Pull Request Process

1. Update the README.md with your changes.
2. Ensure your PR description clearly states what you're adding and why.
3. Be responsive to feedback from maintainers.

## Code of Conduct

This project adheres to a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## Questions?

If you have questions about contributing, feel free to:
- Open a [GitHub Discussion](https://github.com/markshust/marko/discussions)
- Ask in the [Slack community](https://join.slack.com/t/marko-php/shared_invite/zt-3tgwij9r8-Hw4li_NJHYtHtAhh4A_4yQ)
